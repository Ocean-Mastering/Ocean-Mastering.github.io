# Transparent cloud textures

The `cc0-cloud-layer-05.png` and `cc0-cloud-layer-07.png` files are resized derivatives of textures 05 and 07 from **Clouds with Transparency** by WickedInsignia.

- Source: https://opengameart.org/content/clouds-with-transparency
- Original pack: `fx_cloudalphas.zip`
- License: CC0 1.0 Universal / public domain dedication
- Source statement: “I hereby release these assets into the public domain under the CC0 license. You are free to use them commercially or non-commercially.”

The original 2048 × 2048 alpha PNGs were resized to 1280 × 1280 for browser delivery.

`generated-cirrus-layer.png` is a purpose-built 1024 × 1024 transparent raster texture generated for this project with OpenAI's built-in image-generation tool. It depicts a thin, sunlit Caribbean cirrus sheet. No SVG cloud artwork is used.
